# ST.sober Design Brainstorm

## Context
A humorous sobriety tracking dashboard using Taco Time brand colors (greens, gold/amber, dark red, white). The site tracks 10 funny heuristics and shows a 6-month downward trend reaching "warning" levels.

## Idea 1: "Fast-Food Recovery Dashboard" — Retro Diner Meets Data Viz

**Design Movement**: Retro Americana / Diner Aesthetic crossed with modern data dashboards

**Core Principles**:
- Warm, approachable humor through nostalgic fast-food visual language
- Data clarity with personality — charts that tell a story with wit
- Bold color blocking inspired by Taco Time signage
- Playful iconography that doesn't take itself too seriously

**Color Philosophy**:
- Primary: Deep Forest Green (#2E7D32) — grounding, "recovery green"
- Secondary: Taco Time Gold (#F5A623) — warmth, attention, warning states
- Accent: Light Lime (#A5D46A) — freshness, good scores
- Danger: Brick Red (#A52019) — warning levels, declining metrics
- Background: Warm off-white (#FFF9F0) — like a paper placemat

**Layout Paradigm**: Single-page scrolling dashboard with a sticky header "order ticket" style. Sections stacked like a receipt/menu board with clear horizontal dividers.

**Signature Elements**:
- Score gauge styled like a drive-thru order number display
- Metric cards with rounded "taco shell" shapes and subtle food-service textures
- A "receipt" style summary at the bottom

**Interaction Philosophy**: Hover states reveal snarky tooltips. Cards have a slight "wobble" on hover like a bobblehead. Warning states pulse gently.

**Animation**: Cards slide in from the side like items on a conveyor belt. The main score gauge fills with a satisfying liquid-pour animation. Warning indicators have a subtle heartbeat pulse.

**Typography System**: Display: "Fredoka" (rounded, friendly, taco-shop vibes). Body: "DM Sans" (clean, readable). Monospace for data: "JetBrains Mono".

## Idea 2: "Clinical Absurdity" — Medical Chart Parody

**Design Movement**: Swiss/International Style meets medical chart humor

**Core Principles**:
- Deadpan clinical presentation of absurd metrics
- Grid-heavy precision that makes the humor land harder
- Color used functionally as status indicators (green = healthy, red = critical)
- Typography-driven hierarchy with minimal decoration

**Color Philosophy**:
- Primary: Taco Time Green (#2E7D32) — "patient stable" indicator
- Alert: Gold (#F5A623) — "elevated" status
- Critical: Dark Red (#A52019) — "code red" warning
- Neutral: Cool gray (#F5F5F5) background with white cards
- Text: Near-black (#1A1A1A) for clinical readability

**Layout Paradigm**: Dense grid dashboard with a left sidebar showing "patient info" and main area showing vital-sign-style metric cards. Top banner shows current "condition status."

**Signature Elements**:
- EKG-style line charts for trend data
- "Vital signs" cards with blinking status dots
- A "patient chart" header with name, date, and attending sponsor

**Interaction Philosophy**: Minimal animation — clinical precision. Status dots blink. Hovering a metric reveals a "clinical note" (the joke explanation).

**Animation**: Subtle fade-ins. Status indicators blink at different rates based on severity. Charts draw themselves like an EKG readout.

**Typography System**: Display: "Space Grotesk" (geometric, clinical). Body: "Inter" (neutral, medical-form feel). Data: "IBM Plex Mono".

## Idea 3: "The Scoreboard" — Sports Broadcast Meets Recovery

**Design Movement**: ESPN-style sports broadcast graphics with Taco Time sponsorship aesthetic

**Core Principles**:
- Treat sobriety like a competitive sport with stats, rankings, and commentary
- Dynamic, energetic layout with diagonal cuts and bold type
- Color used for team identity (green team = sobriety, red team = relapse risk)
- Data presented as "game stats" with period breakdowns

**Color Philosophy**:
- Primary: Deep Green (#2E7D32) — "home team" color
- Highlight: Taco Time Gold (#F5A623) — "breaking news" ticker, highlights
- Warning: Brick Red (#A52019) — "opponent scoring" / danger zone
- Background: Dark charcoal (#1C2526) — broadcast studio feel
- Accent: Light green (#A5D46A) — positive stat highlights

**Layout Paradigm**: Full-width sections with diagonal clip-paths separating "segments." A persistent top ticker showing live stats. Main content in asymmetric two-column with a large featured stat and smaller supporting cards.

**Signature Elements**:
- Diagonal section dividers like ESPN lower-thirds
- A scrolling "ticker" at the top with real-time quips
- "BREAKING" style alerts when scores drop to warning

**Interaction Philosophy**: Fast, punchy transitions. Cards flip to reveal details. The ticker scrolls continuously. Warning states trigger a "BREAKING NEWS" flash.

**Animation**: Slide-in from edges with slight overshoot. Ticker scrolls smoothly. Score changes animate with a counting effect. Section transitions use diagonal wipes.

**Typography System**: Display: "Oswald" (condensed, bold, sports-broadcast). Body: "Source Sans 3" (clean, readable at speed). Stats: "Bebas Neue" for big numbers.
